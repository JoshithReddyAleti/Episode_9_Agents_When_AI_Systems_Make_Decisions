# Core Concepts — Episode 9

1. **Agent = LLM + tools + decision loop.** Simple definition, powerful implication.

2. **The decision-making location.** Chain: engineer decides. Agent: LLM decides. This shift changes everything.

3. **Reasoning patterns are strategies.** ReAct, Plan-and-Execute, Reflexion — each solves specific problems.

4. **Tools are what agents actually do.** Bad tool design = bad agent. Invest here.

5. **Autonomy has a spectrum.** From "executes given plan" to "sets own goals." More autonomy = more risk.

6. **Multi-agent is expensive.** Justify it with concrete value, not "it sounds cool."

7. **Production agents need 8 components.** Brain, tools, memory, state, goals, control flow, safety, observability. Skip any = demo not product.

8. **Safety is a stack.** Not one control — many layers of defense.

9. **90/10 rule.** 90% of "agents" should be workflows. Real agent decision-making is rare.

10. **Evaluation applies to agents too.** See Episode 8. Tool selection accuracy, task completion, step efficiency, error recovery.
